# Harness

[전체 목차](../README.md)

AI 코딩 도구가 어떻게 일하는지 원리부터 이해하고, 그 위에 하네스를 얹어 AI가 일하는 방식을 안내하고, 강제하고, 들여다보는 방법을 공부한다. 기준 도구는 Claude Code 2.1.x이며, Codex(codex-cli 0.165)와 다른 점은 각 노트 안에 짧게 둔다. 버전에 따라 달라지는 내용은 확인한 버전과 함께 적는다.

## 읽는 순서

아직 작성한 노트가 없다.

## 공부 계획

주제를 통과하면 체크하고, 노트를 위 "읽는 순서"에 올린다.

**Part 1. AI 코딩 도구는 어떻게 일할까**

- [ ] 1. 모델은 글만 만드는데, 어떻게 파일을 고칠까? — 도구 호출과 결과, 에이전트 루프, 멈추는 이유(stop_reason), 에이전트 = 모델 + 하네스
- [ ] 2. AI는 내 규칙을 어떻게 "기억"할까? — 상태 없는 API, 매번 다시 보내는 대화, CLAUDE.md와 스킬이 들어가는 자리, 컨텍스트 창과 압축
- [ ] 3. 규칙을 적어 뒀는데 AI는 왜 어길까? — 글은 지시일 뿐 강제가 아니다, 긴 대화에서 흐려지는 규칙, 압축 뒤 사라지는 규칙

**Part 2. 하네스로 AI를 다루기**

- [ ] 4. 루프의 어디에 코드를 끼울 수 있을까? — 훅이 걸리는 순간들, 막으면서 이유를 돌려주는 방법
- [ ] 5. 무엇을 글로 안내하고, 무엇을 코드로 막을까? — 가이드와 센서, 기계가 판정할 수 있는 규칙과 판단이 필요한 규칙
- [ ] 6. AI가 검사를 통과해야만 끝나게 하려면? — 완료 게이트, 무한 루프 막기

**Part 3. 하네스를 보이게 하고 고치기**

- [ ] 7. 하네스가 무엇을 막았는지 어떻게 알까? — 세션 기록의 구조, 훅으로 남기는 기록
- [ ] 8. 그 기록으로 하네스를 어떻게 고칠까? — 자주 막히는 규칙 찾기, 고친 뒤 효과 재기

**Part 4. 직접 만들기**

- [ ] 9. 작은 관문 만들어 보기 — 개인 저장소에서 훅 하나를 만들고 실제로 돌려 본다

## 기록 기준

- 각 문서는 시작한 질문, 이해한 내용, 헷갈렸던 점, 예제와 확인 결과, 남은 질문, 참고 자료를 연결한다.
- 헷갈렸던 점에는 공부하며 실제로 헷갈린 것과 확인 문제·내 답을 남긴다.
- 설명용 예제와 실제로 실행한 결과를 구분한다. 실행했다면 도구 버전과 실행 환경을 적는다.
- 회사 프로젝트에서 본 사례는 이름과 내용을 일반화해서 쓴다.
