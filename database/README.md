# 데이터베이스

[전체 목차로 돌아가기](../README.md)

데이터를 저장하고 조회하는 방법과 여러 요청이 함께 데이터를 다룰 때의 동작을 공부합니다.

## 공부할 큰 주제

| 주제 | 함께 다룰 내용 |
| --- | --- |
| 데이터 모델링 | 테이블과 관계, 키, 정규화, 제약 조건 |
| 조회와 성능 | SQL, 조인, 인덱스, 실행 계획 |
| 트랜잭션과 동시성 | 트랜잭션, 격리 수준, 잠금, 충돌 |
| 운영과 확장 | 커넥션 관리, 백업, 복제, 데이터 증가에 대응하기 |

예를 들어 인덱스는 조회와 실행 계획을 함께 살펴보며 **조회와 성능** 문서에 정리합니다.

## 정리한 문서

아직 학습 문서를 추가하지 않았습니다. 공부한 큰 주제부터 문서와 링크를 추가합니다.

## 다른 분야와의 연결

- [Java](../java/README.md): 애플리케이션에서 데이터를 다루는 코드와 연결합니다.
- [모니터링과 옵저버빌리티](../observability/README.md): 쿼리 지연과 커넥션 사용 현황을 살펴볼 때 연결합니다.

새 문서는 [학습 문서 양식](../templates/study-note.md)을 사용합니다.
