# Kafka

[전체 목차](../README.md)

Apache Kafka를 4.4 기준으로 다시 공부한다. 예전에 3.x(ZooKeeper 모드) 기준으로 배운 내용을 다시 확인하고, 그 뒤에 바뀐 구조인 KRaft, 새 컨슈머 리밸런스 프로토콜(KIP-848), Share Group 등을 함께 정리한다.

## 읽는 순서

문서는 회차가 아니라 주제 단위로 묶는다. 아직 쓰지 않은 문서는 링크 없이 둔다.

1. [카프카는 왜 필요하고, 큐와 무엇이 다를까?](why-kafka.md)
   - 직접 호출의 문제에서 출발해 RabbitMQ와 저장 방식·일을 나누는 단위·고르는 기준을 비교하고, 처리량이 높은 이유와 전체 구조를 본다.
2. ZooKeeper 없이 카프카는 어떻게 뜰까?
3. [토픽·파티션·오프셋은 어떤 관계일까?](topic-partition-offset.md)
   - 컨슈머 그룹의 파티션 배정 규칙, 커밋 위치와 보존 삭제, `auto.offset.reset`, 파티션 수 정하기를 정리한다.
4. [프로듀서는 메시지를 어느 파티션에 보낼까?](producer-partitioning.md)
   - 키 해시와 스티키 파티셔닝, 같은 키 안의 순서 보장, 키 고르기와 파티션 증설 시 주의점을 정리한다.
5. 프로듀서는 메시지를 어떻게 잃지 않고 중복 없이 보낼까?
6. 컨슈머의 poll()은 내부에서 무엇을 할까?
7. 컨슈머 리밸런스는 왜 바뀌었을까?
8. 오프셋 커밋과 중복 처리는 어떻게 다룰까?
9. Share Group은 컨슈머 그룹과 무엇이 다를까?
10. 복제와 ISR은 데이터를 어떻게 지킬까?
11. KRaft는 메타데이터를 어떻게 관리할까?
12. 카프카는 로그를 어떻게 저장하고 지울까?

## 기록 기준

- 기준 버전은 Apache Kafka 4.4다. 예전 버전과 다른 내용은 어느 버전에서 바뀌었는지 함께 적는다.
- 각 문서는 시작한 질문, 이해한 내용, 헷갈렸던 점, 예제와 확인 결과, 남은 질문, 참고 자료를 연결한다.
- 설명용 예제와 실제로 실행한 결과를 구분한다. 실행했다면 Kafka 버전과 실행 환경을 적는다.
- 실습 코드는 `labs/`에 두고 Kafka 4.4 기준으로 직접 작성한다.
- 참고한 강의와 문서의 내용은 옮기지 않고 내 말로 정리하며, 출처는 각 문서의 참고 자료에 적는다.
