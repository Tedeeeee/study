# 공부한 큰 주제

관련 개념을 하나의 흐름으로 묶는다. 예를 들어 운영체제 기초에서는 프로그램·프로세스·스레드와 실행 권한을 함께 설명한다. 아래 안내 문장은 실제 공부한 내용으로 바꾼다.

## 다루는 범위

이번 문서에서 연결할 개념과 설명할 흐름을 적는다. 이어서 다룰 내용이 있다면 관련 문서로 연결한다.

## 내가 이해한 내용

핵심 개념을 내 말로 설명한다. 세부 개념은 이 문서 안의 소제목으로 나누고, 개념 사이의 관계와 전체 동작 순서를 함께 적는다.

## 헷갈렸던 점

처음 생각했던 내용과 확인한 내용을 함께 적는다. 설명할 수 없는 부분은 질문으로 남긴다.

## 예제와 확인 결과

예제 코드나 명령을 적고, 실제 실행했다면 환경과 관찰한 결과를 기록한다. 실행하지 않은 예제는 설명용이라고 표시한다.
