# 모니터링과 옵저버빌리티

[전체 목차로 돌아가기](../README.md)

서비스의 상태를 확인하고, 문제가 생긴 이유를 조사하는 데 필요한 개념과 도구를 공부합니다. 배운 내용을 실제 서비스에 적용한 과정도 함께 기록합니다.

## 공부할 큰 주제

| 주제 | 함께 다룰 내용 |
| --- | --- |
| 기본 개념 | 모니터링과 옵저버빌리티의 관계, 어떤 질문에 답할 것인가 |
| 관측 데이터 | 로그, 메트릭, 트레이스의 역할과 연결 |
| 수집과 분석 | 계측, OpenTelemetry, 수집 경로, 저장과 조회 |
| 서비스 적용과 운영 | 기록할 정보, 요청 추적, 대시보드와 알림, 보관과 비용 |

예를 들어 로그와 트레이스는 각자의 역할과 요청 흐름에서 연결되는 방식을 함께 정리합니다.

## 정리한 문서

아직 학습 문서를 추가하지 않았습니다. 개념을 공부하고 직접 확인한 내용부터 문서와 링크를 추가합니다.

## 다른 분야와의 연결

- [운영체제](../operating-system/README.md): CPU, 메모리, I/O 사용 현황을 이해할 때 연결합니다.
- [데이터베이스](../database/README.md): 쿼리 지연과 자원 사용 현황을 조사할 때 연결합니다.
- [Docker](../docker/README.md): 컨테이너로 실행한 서비스의 상태를 확인할 때 연결합니다.

새 문서는 [학습 문서 양식](../templates/study-note.md)을 사용합니다.
