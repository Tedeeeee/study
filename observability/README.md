# 모니터링과 옵저버빌리티

[전체 목차](../README.md)

시스템을 이해하기 위해 로그·메트릭·트레이스를 어떻게 연결하고, 어떤 형식으로 수집·관리하며, 어떤 도구로 저장·분석할 수 있는지 공부한다.

## 읽는 순서

1. [로그·메트릭·트레이스는 어떻게 연결될까?](signals-and-correlation.md)
   - 같은 요청의 메트릭, Span, 로그를 비교하고 Trace ID·Span ID·Exemplar로 이어서 분석한다.
2. [관측 데이터를 어떤 형식으로 수집하고 관리할까?](opentelemetry-and-collection.md)
   - 공통 속성과 OTel을 이해하고, 시계열·샘플링·배치·재시도·보관 정책을 살펴본다.
3. [APM 서비스와 오픈소스 조합은 어떻게 다를까?](apm-and-backends.md)
   - 대표 제품과 OSS 조합의 수집·저장·조회 흐름, 직접 구현할 때의 책임을 비교한다.

## 기록 기준

- 각 문서는 시작한 질문, 이해한 내용, 헷갈렸던 점, 예제와 확인 결과, 남은 질문, 참고 자료를 연결한다.
- 설명용 데이터와 실제로 실행한 결과를 구분한다.
- 일반적인 개념과 학습 중 검토한 프로젝트 적용안을 구분한다.
- 현재 글들은 개념 학습 기록이며, 계측·저장 시스템을 구현하거나 운영에 배포한 결과는 아니다.
