# 운영체제

[전체 목차로 돌아가기](../README.md)

프로그램이 실행되고, 메모리와 파일을 사용하며, 다른 작업과 함께 동작하는 흐름을 공부합니다. Docker를 이해하는 데 필요한 운영체제 개념도 이곳에 모읍니다.

## 공부할 큰 주제

| 주제 | 함께 다룰 내용 | 기록 상태 |
| --- | --- | --- |
| 운영체제 기초 | 운영체제의 역할, 프로그램과 프로세스, 스레드, 실행 권한, 장치 파일 | 공부 중 · 문서 정리 예정 |
| 메모리 관리 | 메모리 계층, 가상 메모리, 프로세스의 메모리 공간과 공유 | 학습 예정 |
| 파일과 I/O | 파일 시스템, FD, Page Cache, 읽기와 쓰기, 대기와 완료 | 파일 읽기 흐름 정리 |
| 동시성과 실행 관리 | 스케줄링, 문맥 교환, 경쟁 상태, 동기화 | 후속 학습 예정 |

세부 개념은 각 큰 주제 문서의 소제목으로 정리합니다. 예를 들어 프로그램·프로세스·스레드는 실행 구조를 설명하는 한 흐름 안에서 함께 다룹니다.
