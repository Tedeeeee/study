# Java

[전체 목차로 돌아가기](../README.md)

Java 코드의 의미와 실행 과정을 이해하고, 작은 예제로 동작을 확인합니다.

## 공부할 큰 주제

| 주제 | 함께 다룰 내용 |
| --- | --- |
| 언어와 객체 지향 | 타입, 객체, 상속과 조합, 인터페이스, 예외 |
| JVM과 메모리 | 컴파일과 실행, 클래스 로딩, 메모리 구조, GC |
| 동시성 | 스레드, 공유 데이터, 동기화, 실행 작업 관리 |
| 표준 라이브러리와 I/O | 컬렉션, 파일, 스트림, 자원 관리 |

예를 들어 공유 변수와 락은 스레드의 실행 흐름을 따라 **동시성** 문서에 함께 정리합니다.
