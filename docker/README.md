# Docker

[전체 목차로 돌아가기](../README.md)

컨테이너의 동작 원리를 이해하고, 애플리케이션의 실행 환경을 구성하는 방법을 공부합니다.

## 공부할 큰 주제

| 주제 | 함께 다룰 내용 |
| --- | --- |
| 컨테이너의 원리 | 프로세스 격리, Namespace, cgroups, 파일 시스템 |
| 이미지와 빌드 | 이미지 구조, 레이어, Dockerfile, 빌드 과정 |
| 실행 환경 구성 | 컨테이너 실행과 종료, 환경 설정, Docker Compose |
| 네트워크와 저장 공간 | 컨테이너 통신, 포트 연결, 볼륨, 데이터 유지 |

명령어는 해당 큰 주제의 실행 흐름과 함께 기록하고, 실습한 경우 실행 방법과 결과를 남깁니다.

## 정리한 문서

아직 Docker 학습 문서를 추가하지 않았습니다. 현재 강의에서 배우는 기초 개념은 [운영체제](../operating-system/README.md)에 정리하고, 컨테이너를 다룰 때 이곳에 문서를 추가합니다.

## 다른 분야와의 연결

- [운영체제](../operating-system/README.md): 컨테이너를 이해하기 위한 실행 구조와 자원 관리의 기초입니다.
- [네트워크](../network/README.md): 컨테이너 간 통신과 외부 요청의 경로를 연결해서 봅니다.
