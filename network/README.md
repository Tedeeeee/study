# 네트워크

[전체 목차로 돌아가기](../README.md)

프로그램 사이에서 데이터가 오가는 과정과 웹 요청이 처리되는 흐름을 공부합니다.

## 공부할 큰 주제

| 주제 | 함께 다룰 내용 |
| --- | --- |
| 네트워크의 기본 구조 | 계층, 주소, IP, 라우팅 |
| 전송과 연결 | TCP와 UDP, 연결의 시작과 종료, 데이터 전달 |
| 웹 통신 | DNS, HTTP, HTTPS, 요청과 응답 |
| 서비스 네트워크 | NAT, 프록시, 로드 밸런싱, 통신 경로 확인 |

예를 들어 TCP의 연결과 종료는 **전송과 연결**이라는 흐름 안에 모아 정리합니다.

## 정리한 문서

아직 학습 문서를 추가하지 않았습니다. 공부한 큰 주제부터 문서와 링크를 추가합니다.

## 다른 분야와의 연결

- [운영체제](../operating-system/README.md): 소켓과 I/O, 스레드의 대기를 연결해서 봅니다.
- [Docker](../docker/README.md): 컨테이너 사이의 통신과 외부 접근을 이어서 공부합니다.

새 문서는 [학습 문서 양식](../templates/study-note.md)을 사용합니다.
